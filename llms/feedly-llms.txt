- [Vulnerability Agent](https://developers.feedly.com/reference/vulnerability-agent.md): Query the Vulnerability Agent.  **How to get your query JSON**: Open any saved or ad-hoc Vulnerability Agent search in the Feedly UI and click the **API** button at the top of the page. Feedly generates the complete JSON payload for you — paste it directly into the request body. You do not need to construct the body manually.  **Custom time windows**: Use `"type": "Custom"` with full ISO 8601 datetimes for `start` and `end` to poll on any cadence (e.g. every 4 hours) without overlapping bucket boundaries. This is useful for automated workflows (SOAR, SIEM) so each poll returns only new records with no overlap.  **Request body fields**: - `layers` (array) — ordered filter layers; filters within a layer are   OR'd, layers are AND'd together  - `layers[].filters[].field` — filter dimension: `period`, `trending`,   `created`, `exploited`, `poc`, `weaponized`, `inCisaKev`, `cvssScore`,   `cvssEstimate`, `cvssVector`  - `layers[].filters[].value` — value depends on field:   period → `{"type": "Last7Days"|"Last30Days"|"Last3Months"|"Last6Months"|"Custom", "label": "...", "start": "ISO datetime", "end": "ISO datetime"}`;   cvssScore → `{"gte": 9}`;   cvssEstimate → `"HIGH"|"MEDIUM"|"LOW"`;   cvssVector → string component e.g. `"AV:N"`, `"PR:N"`, `"UI:N"`;   boolean fields → `true`  - `count` (integer, optional) — max results per page - `continuation` — pagination token from the previous response - `sort` — `{"field": "cveId"|"cvssScore"|"epssScore"|"publishedDate", "order": "asc"|"desc"}`

To find your team's Custom Agents, filter the response for items where `type` is `customAgent`, then pass each one's `id` to `GET /custom-agents/{id}` to fetch that agent's rows.

Find the `id` to use here from a `customAgent`-type item returned by `GET /dashboards`, and use that same item's `schema.columns` to interpret each row's `cells`.
